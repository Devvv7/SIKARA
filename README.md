SIKARA — Inventory Management System

SIKARA (Sistem Inventaris Kantor Imigrasi Ngurah Rai) is a web-based inventory management system developed to support the management and recording of inventory at the Ngurah Rai Immigration Office.

The application provides features for managing inventory items, recording incoming and outgoing transactions, tracking stock by batch, monitoring stock movements through stock cards, generating transaction reports, searching data, pagination, and exporting reports to PDF.

✨ Features
📦 Inventory Management
View inventory items.
Add new inventory items.
Edit existing items.
Delete items that have no transaction history.
View item details and stock history.
Search by item code or item name.
Pagination with configurable items per page.
📥 Incoming Transactions
Record incoming inventory transactions.
Store transaction dates, quantities, unit prices, and descriptions.
Automatically increase the item's total stock.
Maintain inventory stock based on individual incoming batches.
📤 Outgoing Transactions
Record inventory usage or distribution.
Validate stock availability before processing a transaction.
Automatically decrease the item's total stock.
Decrease stock from inventory batches using the FIFO (First In, First Out) method.
Prevent outgoing transactions when available stock is insufficient.
📊 Stock Card
View the stock movement history of a selected item.
Display incoming and outgoing quantities.
Calculate running stock balances.
Display total incoming stock, outgoing stock, and ending balance.
Export stock cards to PDF.
📑 Transaction Reports
View incoming and outgoing transaction history.
Filter transactions by date range.
Filter by inventory item.
Filter by transaction type.
Search by item code or item name.
Calculate running stock balances.
Display transaction summaries.
Pagination with configurable items per page.
Export transaction reports to PDF.
🔐 Authentication
User login.
Show/hide password.
Logout.
Customized authentication interface.
